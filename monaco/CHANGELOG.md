# Changelog

All notable changes to this project are documented in this file.

## 0.1.0 - 2026-09-14

- Add `swagger-ui-monaco` with schema-aware JSON request, object parameter, and response surfaces plus a plain-text fallback.
- Add `swagger-ui-monaco-dist`, bundling Swagger UI 5.32.15 and self-hosted Monaco 0.56.0 browser assets.
- Add `swagger-ui-monaco-express`, composing the enhanced assets with the `swagger-ui-express` 5.0.1 API.
- Add OpenAPI 3.0 and 3.1 schema projection, local reference handling, direction-aware `readOnly`/`writeOnly` suppression, and compatibility warnings.
- Add clean-consumer package verification and GitHub Actions CI/release workflows.
